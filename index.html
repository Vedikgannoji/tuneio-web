What tuneio does

A lightweight, local HTTP proxy designed for finite inspection, intentional caching, and rigorous before-and-after verification.

Live API monitoring

See request volume, latency, and errors by endpoint as traffic passes through tuneio’s local proxy.

tuneio monitor

Adaptive caching you approve

Review which public GET responses can be cached and which writes should invalidate them.

tuneio optimize enable

Before-and-after comparisons

Repeat the same GET workload and compare latency and cache hits.

tuneio compare

Get started with tuneio

Install the CLI using your preferred Python package manager.

Python 3.11+
$ pip install tuneio

When installing with pip, use an activated virtual environment (such as .venv).

Launch command
$ tuneio

Run tuneio from the project folder you want to work in.
