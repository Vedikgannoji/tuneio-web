Install and run tuneio

Install the CLI with your Python package manager and launch it from your project folder.

Python 3.11+
$ pip install tuneio

When installing with pip, use an activated virtual environment (such as .venv).

  1. 01

    Install

    Use pip, pipx, or uv above.

  2. 02
